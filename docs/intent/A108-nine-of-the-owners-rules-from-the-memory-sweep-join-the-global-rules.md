# A108 Nine of the owner's rules from the memory sweep join the global rules

Nine rules the owner gave in one project each, held in that project's memory, join "How to work" in `global/CLAUDE.md`, each with its reason in `global/RATIONALE.md`:

- The owner's open questions go together, up to four in one ask (tagents, 2026-10-24).
- Dry and blunt (`os/main`, 2026-08-19).
- An untagged "how do I" is an `Ask:` (`onitama`, 2026-11-14), a sentence of the tagged-line rule.
- The company is Iquall, capital I only (tagents, 2026-08-25), a sentence of the typo rule.
- A convention the owner shows by example is generalised and gated (generic-app, 2026-10-22).
- A name in the owner's example is a suggestion (generic-app, 2026-10-22).
- Every diagram is a mermaid block (tagents `demo-misc`, 2026-11-03).
- A file only a mechanical sweep touched keeps its tells (tagents, 2026-10-27), a sentence of the tells rule.
- This machine is Nix-managed (`os/main`, `misc/slides` and `addictive_idle`, from 2026-07-30).

## Context

`docs/analyses/memory-sweep-plan.md` proposed eleven, each tried in the project that heard it (`O20`, a rule spreads beyond one project only once its trial shows it works). The owner approved the plan on 2026-11-18 and took the nine recommended. Under `A103` (memory holds only what no file can), the memories that held them are deleted once the rules are in.

## Options

- Downloads behind a login, fetched from the logged-in page. Rejected: a technique used once, kept in `facu/ssoo`, at 41 words on every turn of every project.
- A visual design starts from its domain. Rejected by the owner: the words were about one app, and the copy stays in `sofi/gallery`'s `docs/architecture.md`.

## Consequences

The nine add about 220 words to `global/CLAUDE.md`, which every project's rulebook carries. This repository's rulebook reads 3,912 of 7,500 words with them.
