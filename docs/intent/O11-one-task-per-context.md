# O11 One task per context

One task per context. A change of idea starts a fresh context, so unrelated or conflicting tasks never share one.

## Changes

When a context is cleared, and what a session does when a prompt is about something else.

## Known by

No context holds two unrelated tasks. A change of idea starts with a handoff and a clear, with nothing of the old task carried into the new one by accident.

The owner's words, said of `session-kit` on 2026-10-24 under the goal "reduce agent confusion when context grows", which folded into `G2` and `G3` when the two ladders merged.
