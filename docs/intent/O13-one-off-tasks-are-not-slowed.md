# O13 One-off tasks are not slowed

Simple and one-off tasks are not slowed. A formal process is not applied where it would make the work worse.

## Changes

What a session does before a one-off task: nothing beyond the task.

## Known by

A question, a read, a single edit or a quick fix writes no entry and runs no step of the process. The two signs in `global/goals-objectives-actions.md` decide which a task is.
