# O6 A session's word is not the proof

A step that matters, tests run, checks passed, a handoff written, leaves a record a program wrote, and done rests on that record alone.

## Changes

What a claim of done rests on.

## Known by

A test run leaves its log, kept by the plugin, and a claim of green with no log behind it is caught before the owner reads it.

Inferred from G2, "We can't trust the agent to say 'I ran the tests', because it may believe it did when it didn't".
