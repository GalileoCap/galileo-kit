# O5 Work moves down to programs

Every step of the work has a kind, human-only, agent or program, and a step moves to the program kind wherever a deterministic program can do it.

## Changes

Who does each step, and what the owner is left to think about.

## Known by

Each rule in the global rules says whether a program enforces it, marked refused, or a session reads it. The share enforced by programs grows with each kit release.

Inferred from G2, "as many things as possible would be moved to deterministic programs that require no 'intelligent' decision making".
