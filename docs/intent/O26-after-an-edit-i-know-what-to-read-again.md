# O26 After an agent edits a document I reviewed, I know which parts to read again

When a session edits documents the owner has read and given feedback on, the owner knows, section by section, which to read again whole, which to read as a diff and which to skip, and no change goes unseen. The answer comes from a program reading the files, so it costs no round with the session and does not rest on the session's account of its own edits.

In the owner's words, 2026-11-18:

> The specific need is when iterating on a spec: the agent writes a few markdown files, I read through them and give feedback, they edit the files. Here I don't know what to read, what changed? I can ask the agent, but it wastes a round and I'd need to trust them (they could miss something). I can look at the diff in git, but it's hard to read and it's worse when whole sections were removed or changed.

## Changes

The owner's review of a document a session revised, Markdown first.

## Known by

A revision the owner reads through the tool's page alone, with nothing changed found later that the page did not show.
