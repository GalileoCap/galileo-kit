# Mods read for the kit

Read on 2026-10-25, on the owner's ask to analyse effortless, replay-theater and agent-profiler, find more worth reading, and learn from their code to improve `session-kit`. The three named mods have full reviews under `docs/reviews/`. Eleven more were read for their patterns only, with no verdict, and the community catalogue was surveyed to choose them. Every clone sits under `~/devel/galileo/misc/mod-clones/` at the commit below and was never loaded, built or run, by `A1` (review from a clone). Line numbers are the clone's. Nothing here is decided: each candidate names what it serves and what it costs, and the last section lists what waits on the owner.

## What else is out there

The catalogue, scanned on 2026-10-22 against Claude Code 2.1.308, lists 6,097 mods in 3,169 repositories: 511 at L0 (draws and remembers), 1,515 at L1 (reads), 3,220 at L2 (writes, runs or drives Claude), 660 at L3 (network). 1,942 see every tool call and 1,767 every prompt. The shortlist came from its descriptions matched against the kit's concerns, top repositories by stars first: about 99 mention a handoff, 211 compaction, 272 the context window, 110 the transcript, 69 loops or retries. The context meter and the handoff are the most crowded kinds, and the kit's own ground. Three of the mods read (effortless, compact-adviser, and a family of `*-jev-compaction` mods in the catalogue) send transcript snapshots to TypeSafe's Jev, a third-party judging service. A few repositories publish most of the careful work: YeonwooSung's seventeen mods share one generated adapter and one redactor, and Anthropic's playground mods reappear, rewritten, in hamzafer's.

## Engine facts the mods document

Each was written down by a mod's author from live runs. Those checked against the 2.1.308 types are marked checked.

- `$.session.compact` runs through every hook but its caller's, and rejects while a turn runs (compact-adviser `hooks/register.ts:16-19`). The chain's own compaction therefore never reaches the backstop of `A18` (a backstop for the engine's own compaction), and the chain passes the instructions itself.
- `$.prompt.submit` rejects text that starts with `/` and expands no slash command or `@file`. A command goes through `$.command.run` (compact-adviser `hooks/register.ts:20-22`).
- `$.config.set` hot-reloads the module and raises `session.start` again (compact-adviser `hooks/register.ts:13-15`). A hot reload runs `register` in a fresh environment and drops its timers (checked, reference.md line 73). Module variables survive `/clear` and are lost on a reload, and `$.store` survives both.
- After `/clear` no `session.start` fires. `session.end` arrives with reason `clear` and the process goes on under a new session id (context-inspector `hooks/register.tsx:146-153`). This bears on the open question whether `$.session.turns()` starts over at a desktop `/clear`.
- A toast within two seconds of another is dropped, so a result goes to `$.ui.status` or `$.ui.log` (compact-adviser `hooks/register.ts:387-389`).
- `PromptOrigin` is a closed set of sixteen kinds, `composer`, `bridge`, `sdk`, `task-notification`, `scheduled-trigger`, `plugin` and `unclassified` among them, listed whole in `A46` (checked, types line 9255 on).
- Probed on 2.1.308 with a plugin of the kit's own in the scratchpad, for M17: `on` cannot be wrapped. A module that hands a concern `timed(on)` in place of `on` is refused by the validator, which lets the value of `on` be passed, called and given a `.catch` and nothing else. So the wrapper M17 names, timing each concern's hooks around their handlers, cannot be built.
- Probed the same way: inside one hooks module the hooks nest as a single link of the chain, first registered outermost. A hook's `next.trace` lists the links beneath the module (other plugins' hooks and the engine) with each one's own time in `ms`, waits taken out, and never the module's own hooks. A glob (`tool.*`) or `*` hook loads beside an unmatched hook of an exact event name.
- Probed the same way: a function another file of the plugin exports may take `$`, and the validator lists its calls (`calls: $.session.cwd (via cwdOf)`). The loader refuses `$` passed only to a function nested inside another. `$.fs.write` creates a file's directories, `$.fs` has no append, and a read or a write over 4 MiB rejects. `performance.now()` is a global of the module's environment.
- `$.session.usage({ breakdown: 'summary' })` lists each memory file the context carries with its path, where it was loaded from (`Project`, `User`, `Local`, `Managed`, `AutoMem`) and its estimated tokens, counted locally with no request (checked, types lines 11456 and 12344-12360).
- A resume or fork carries the cache's state and the price of re-writing it in `classic.SessionStart` (checked, types lines 12261-12273). The split of cache writes by lifetime at line 17819 is inside `BuiltinToolResults.Agent`, the Agent tool's result, so it states a subagent's. The model-switch hooks carry `cache_ttl` (lines 8028, 8114). The main loop's `TurnUsage` carries the four counts and the model, with no split (line 14569).

## Patterns seen and left

- Rewriting em dashes into commas before a write runs (rulebook-guard `hooks/register.ts:22-91`). The global tells rule says a dash swapped for a comma is the same sentence.
- A judge model on every prompt (effortless) or on every turn end (compact-adviser). The first holds each prompt for the judge, against `O13` (one-off tasks are not slowed), and `A19` rejected a model call per prompt as its option 3. Both send transcript text to TypeSafe when a key is set (compact-adviser `lib/snapshot.ts:1-25`, up to 64 recent messages). `O15` (routine work takes the cheaper path), still proposed, gives neither ground.
- A self-updater inside a mod (effortless). The kit's updates stay `claude plugin update` after a version bump.
- Refusing tool calls past a threshold so the turn hands off (auto-handoff `hooks/register.tsx:454-473`). It stacks with the guard, and the chain already stops at a clear point.
- A detached web server on the Tailscale address to serve briefs to a phone (auto-handoff `hooks/register.tsx:130-141`).
- A `/clear` run with no person at the prompt (auto-handoff). `A19` keeps the clear behind the person's press.

## Decided on 2026-10-25

The owner read the analysis and answered.

- The three verdicts stand: reject effortless, replay-theater and agent-profiler. No fork of any of them: what is worth having is re-implemented in the kit, in its own shape and under its own tests.
