# The shape of code

These rules are for a project that takes the pure-core shape, and a project takes them by naming this file in its `CLAUDE.md` with an `@` line (the marketplace clone at `~/.claude/plugins/marketplaces/galileo-kit/global/CODE.md`) or by a copy. A shell-script repository or a document project has no core and no shell, and loads nothing here. The reasons are in `RATIONALE.md` beside this file, under the same heading. The project names its layers under `layers` in `.claude/claude-kit.json`, and `session-codeintel layers` writes the gate that holds the first rule.

- **Code is pure by default, and an effect names itself.** Pure code does no I/O, reads no clock and draws no randomness, and lives in the core. Effects live in the shell, and every function there names its effects in a line the gate reads: `Effects:` in a docstring, `@effects` in a JSDoc tag. A function with no effects belongs in the core. An effectful operation is split into pure steps around the effect itself, and the decisions go in the core.
- **Failures are values.** A function returns `Err`, or takes a `fail` that lists the errors it may fail with, and the type checker holds every caller to the list. `raise` and `throw` are refused outside the place that unwinds them. A failure is handled only at a boundary (a route, a command's `main`, a worker's run), in one statement where a combinator can, with a `match` only where an arm runs several statements.
- **A check returns a proof, and the write takes it.** A write takes the proof with its target, so it can only act on what was checked. A read of what a viewer may see takes a proof too. Authority is a type, made only by the module that checks.
- **What leaves the server is a view.** A view is a type made to be shown, and the encoders take nothing else, so a row cannot leave unshaped. A secret shown is a `Redacted`, which only `redact` makes.
- **A unit is a type.** A moment is a `Millis`, a token a `TokenDigest`, a password a `PasswordHash`. A duration, such as the difference of two moments, stays an integer.
- **A thing shown in two places is a component named for what it shows**, made on the second use. A look shared by different things is an entry in a looks file. A page writes neither, and `session-codeintel looks` fails on a class string written twice.
- **A structural rule is held by a tested gate.** A new component that owns a primitive, a new proof, a new boundary gets a rule with its test (an ast-grep rule, a type), or the next twenty arrive the same way the first did.
