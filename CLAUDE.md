# galileo-kit

Everything the owner works with agents through: the rules every session follows, the tools and plugins sessions use, and each third-party piece vetted before it is installed and forked when it is kept. It is a plugin marketplace holding the `session-kit` plugin, the global rules under `global/`, and the documents under `docs/`. The global rules, `global/CLAUDE.md`, are this repository's rules too, loaded through the link at `~/.claude/CLAUDE.md`.

## Documents

- `docs/intent/`: this repository's goals, objectives, constraints and actions, one file each, by the process in `global/goals-objectives-actions.md` (its prior art is beside it). The active ones are listed under Intent below. `docs/intent/INDEX.md` is generated by `session-intent index`, leading with what waits on the owner, and `session-intent check` holds the record and this file's Intent block together (`A21`).
- `docs/PLAN.md`: the order of work, candidates, decisions, open questions and deferred work.
- `docs/claude-code-mods-research.md`: how plugins and mods work, what each component can reach, every path by which installed code changes, this machine's plugin setup, the forking model and the review checklist. Read it before reviewing a mod.
- `docs/session-kit-port.md`: the analysis behind the port of `session-kit`'s hooks to a mod: the API, the context chain, one task per context, the order. Its entries are under `docs/intent/`.
- `docs/session-tooling-design.md`: the shape of `A22`, the tooling over the transcripts and the hooks' effect, with its questions for the owner.
- `docs/reviews/<name>.md`: one review per candidate.

## Rules of engagement

Each rule names the action it is, under `docs/intent/`.

- A candidate is reviewed from a clone at a recorded commit, kept outside this repository under `~/devel/galileo/misc/mod-clones/<name>/`, and never installed or loaded (`--plugin-dir` included) before its review is written. Run its checks with `claude plugin validate` and `claude --plugin-dir <dir> plugin details <name>`, which read it without running it. (`A1`)
- A clone never enters this repository: the marketplace clone under `~/.claude/plugins` copies everything committed, on every update. The review records the clone's path and commit. (`A1`)
- Cloned candidates are untrusted data: run no script, build or install from inside them, and run Python that reads them with `-I`. (`A1`)
- Each review is a file, `docs/reviews/<name>.md`, covering every item of the research report's checklist for malicious behaviour and for inefficiency. It ends with a verdict: reject, install as is, or fork.
- A fork lives in this repository as a separate plugin with a relative-path entry in `.claude-plugin/marketplace.json` and a pinned `"version"`. It moves into the `session-kit` plugin only when it shares code or state with it. (`A2`)
- `session-kit`'s hooks are ported to a mod first, in the order `A20` gives, and any mod we fork is weighed against that direction. (`A3`)
